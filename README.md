# 🌐 First Website Attempt

My first ever attempt at making a website when I was 17.

I watched one tutorial, immediately thought I understood web development, and jumped straight into building a full website without really knowing how to structure files, organize code, or follow any proper practices.

Looking back at it now, it honestly wasn’t the best. Most of the project was held together by trial and error, random fixes, and me learning things as I went along.

## ⚠️ Note

This project is pretty lackluster compared to what I imagined it would be at the time, but I’m keeping it public because it shows the start of my learning journey.
